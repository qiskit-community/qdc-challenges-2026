# Troubleshooting

Find the message or symptom, then apply the fix. Numbered errors come from IBM Quantum. The [error code reference](https://quantum.cloud.ibm.com/docs/en/errors) explains every code, and the Qiskit Docs MCP server looks codes up by number (see [MCP servers](../reference/ai-tooling.md#qiskit-mcp-servers)).

## Installing and importing

| Symptom | Cause | Fix | See |
|---|---|---|---|
| `ModuleNotFoundError: No module named 'qiskit_ibm_runtime.executor_sampler'` (or `executor_estimator`) | `qiskit-ibm-runtime` older than 0.50 | Run the importing code with runtime 0.50 (`pip install qiskit-ibm-runtime==0.50.0`, after `pip install -r requirements.txt` if that file pins 0.49). Keep a notebook's own 0.49 pin for that notebook | [Sampler and Estimator](../reference/ibm-quantum-compute-client.md#sampler-and-estimator-client-side-primitives), [Versions and environment](getting-started.md#versions-and-environment) |
| `ModuleNotFoundError` for the `qc_grader.challenges` module your notebook imports | Your `qc-grader` predates the QDC 2026 graders; as of 20 October 2026, the latest release on PyPI (2026.9.29) does not include them | Install the `qc-grader` release the organizers announce | [Grading](getting-started.md#grading-with-qc-grader) |
| `TypeError` or `AttributeError` from `add_pauli_checks(..., stabilizers=...)`, `CheckedCircuit.dope()` or `estimate_fault_rates()` | PyPI `qiskit-paulice` 0.2.1 lacks them | Install GitHub `main`, which needs a Rust toolchain: `pip install --force-reinstall --no-deps git+https://github.com/Qiskit/qiskit-paulice.git` | [Spacetime Pauli checks](../reference/qiskit-addons.md#spacetime-pauli-checks-qiskit-paulice) |
| `ImportError` for the shaded-light-cone bound APIs after you installed the GitHub commit | pip kept the PyPI 0.1.0 already installed, because the commit reports the same version | Install the commit in a fresh environment | [Shaded light cones](../reference/qiskit-addons.md#shaded-light-cones-qiskit-addon-slc) |
| `ImportError: cannot import name 'distribute_task' from 'qiskit_serverless'` (or `get`) | `qiskit-serverless` 0.37 removed the Ray helpers | Restructure the parallel step without them; older Serverless guides still use them | [Write, upload and run a workflow](../reference/managed-workflows.md#write-upload-and-run-a-workflow) |
| pip resolves `qiskit-serverless` 0.35 or 0.36 against runtime 0.50 and fails | Those versions require runtime below 0.50 | Use `qiskit-serverless` 0.38 with `qiskit-ibm-catalog` 0.22 | [Versions and environment](getting-started.md#versions-and-environment) |
| `pip install mthree` compiles from source and fails | mthree 3.0.0 has wheels for Python 3.9–3.12 only | Use Python 3.12, or install a C compiler | [Versions and environment](getting-started.md#versions-and-environment) |
| `qpy.load` rejects a file from a teammate | Qiskit 2.6 writes QPY format 18, which Qiskit 2.5 cannot read | Write with `qpy.dump(..., version=17)`, or use one Qiskit version across the team | [QPY](../reference/qiskit-sdk.md#saving-circuits-with-qpy) |
| `plot_gate_map` or `plot_error_map` asks for Graphviz | Qiskit draws these with Graphviz's `dot` program | Install the Graphviz system package, not the `graphviz` pip package | [Practical tips](testing-and-tips.md#practical-tips) |
| `QiskitBackendNotFoundError: No backend matches the criteria` | The QPU is not available to your instance (plan or region) | List what you can use with `service.backends()` and pick the matching instance | [IBM Quantum account](getting-started.md#ibm-quantum-account), [QPUs at a glance](../reference/hardware.md#qpus-at-a-glance) |

## Building and transpiling circuits

| Symptom | Cause | Fix | See |
|---|---|---|---|
| Error 1517: "Circuits do not match the target definition (non-ISA circuits)" | The circuit was transpiled for another target, or not at all | Transpile against the backend you run on, loaded with the same `use_fractional_gates` and `calibration_id` | [Transpiler](../reference/qiskit-sdk.md#transpiler-preset-and-custom-pass-managers), [Calibrated instructions](../reference/ibm-quantum-compute-client.md#specially-calibrated-instructions-and-calibration-sets) |
| `BuildError: Non-Clifford and unbound fractional entanglers are only supported for Twirl with 'GroupMode LOCAL_PAULI'` from `run()` of the client-side Sampler or Estimator | Gate twirling on a circuit with fractional `rzz` gates: `resilience_level = 2`, `twirling.enable_gates = True`, PEA or PEC all switch it on. The client-side primitives raise this on your machine, before any job is submitted; the legacy primitives returned error 1519 | Set `options.twirling.group = "local_pauli"` (a partial twirl), switch gate twirling off (`resilience_level = 0` plus the options you want), or transpile without fractional gates | [Fractional gates](../reference/ibm-quantum-compute-client.md#fractional-gates), [Twirling options](../reference/ibm-quantum-compute-client.md#twirling-options-in-the-primitives) |
| Error 1519: "One or more circuits contain fractional gates, which cannot be used with the given options or other circuit instructions" | PEC, PEA or Pauli gate twirling (including `resilience_level = 2`) requested on a circuit with fractional gates, with the legacy server-side primitives | Switch those options off, or remove the fractional gates. The client-side primitives can twirl fractional `RZZ` gates partially with `options.twirling.group = "local_pauli"` | [Fractional gates](../reference/ibm-quantum-compute-client.md#fractional-gates), [Twirling options](../reference/ibm-quantum-compute-client.md#twirling-options-in-the-primitives) |
| A job with parametric `RZZ` gates fails on the angle | Fractional `RZZ` takes only angles in (0, π/2] | Bind angles in range. For a negative angle, put an X on one qubit before and after the gate, or let `FoldRzzAngle` rewrite bound angles | [Fractional gates](../reference/ibm-quantum-compute-client.md#fractional-gates) |
| Error 1553: "Parametric instructions other than RZ gates are not supported with dynamic circuits" | Unbound parameters on gates other than `rz` in a circuit with mid-circuit measurements, resets or feed-forward | Bind those parameters locally before you submit, or rewrite the circuit so that only `rz` gates carry parameters | [Dynamic circuits](../reference/ibm-quantum-compute-client.md#dynamic-circuits-and-resets) |
| Error 1601: "A circuit contains a delay that is not a multiple of dt" | A hand-set delay | Let the scheduling passes set delays, or use `stretch` | [Dynamic circuits](../reference/ibm-quantum-compute-client.md#dynamic-circuits-and-resets), [DD passes](../reference/qiskit-sdk.md#dynamical-decoupling-passes) |
| `QASM2ParseError: ... 'sx' (or 'swap', 'u') is not defined in this scope` | `qelib1.inc` has none of them | `qasm2.load(path, custom_instructions=qasm2.LEGACY_CUSTOM_INSTRUCTIONS)` | [Advantage Tracker](../reference/ecosystem.md#reference-circuits-the-quantum-advantage-tracker) |
| `QASM2ParseError: can only handle OpenQASM 2.0, but given 3.0` | The file is OpenQASM 3 (most tracker circuits are) | `qiskit.qasm3.load(path)`, which needs `qiskit-qasm3-import` | [Advantage Tracker](../reference/ecosystem.md#reference-circuits-the-quantum-advantage-tracker) |
| `TranspilerError: 'y in dd_sequence is not supported in the target'` when you pad idle time | IBM targets (Heron and Nighthawk) have no `y` gate | Pad with an X–X sequence, or use the primitives' dynamical decoupling option | [DD passes](../reference/qiskit-sdk.md#dynamical-decoupling-passes) |
| A fake backend has no `rzz` or `rx` gates | Fake-backend snapshots leave out fractional gates by default | `fake.refresh(service, use_fractional_gates=True)` adds them from the real backend; it needs an account with access to that QPU, but no QPU time | [Fake backends](../reference/ibm-quantum-compute-client.md#fake-backends-and-local-testing-mode) |
| Folded circuits show no extra noise | The transpiler canceled the U†U pairs | Put barriers between U, U† and U before you transpile | [Practical tips](testing-and-tips.md#practical-tips) |
| The service cannot parse a circuit's global phase | A pass manager run on free parameters left a long symbolic phase | Bind the parameters before you transpile. For a circuit you only sample or measure, you can also set `isa.global_phase = 0`, since a global phase changes no measured result | [Practical tips](testing-and-tips.md#practical-tips) |
| `samplomatic.build` fails on a boxed circuit that already carries `xslow` non-Markovian error checks and twirled measurements | The checks were added before `build` | Run `build` on the boxed circuit first, then add the checks to the template it returns, as the shaded-light-cone and PNA tutorials do | [Non-Markovian error checks](../reference/noise-management.md#post-selection-on-non-markovian-error-checks) |

## Submitting and running jobs

| Symptom | Cause | Fix | See |
|---|---|---|---|
| Error 1515: "The primitive inputs are not valid" | For example, a circuit without measurements sent to the Sampler or `Executor` | Add measurements and check the PUB shapes | [Practical tips](testing-and-tips.md#practical-tips) |
| Error 1501: "Mismatch between the number of qubits and observables", or the Estimator rejects an observable's size | The observable is defined on the logical qubits | Map it first: `observable.apply_layout(isa.layout)` | [Sampler and Estimator](../reference/ibm-quantum-compute-client.md#sampler-and-estimator-client-side-primitives) |
| Error 1520: "Circuits or PUBs exceed one or more system limits" | Too much in one job | Split the work across jobs in a `Batch` | [Execution modes](../reference/ibm-quantum-compute-client.md#execution-modes-job-batch-and-session) |
| Error 1352: "You are not authorized to run a session when using the {} plan" | Sessions are not available on the Open Plan | Use job mode or a `Batch` | [Execution modes](../reference/ibm-quantum-compute-client.md#execution-modes-job-batch-and-session) |
| Error 1304: "Job {} exceeded the max_execution_time of {} seconds" | The job ran longer than its limit | Raise `max_execution_time` (a top-level option in runtime 0.50) or split the job | [Budgeting QPU time](../reference/ibm-quantum-compute-client.md#budgeting-qpu-time) |
| Error 1602: "Supplied rep_delay is not in the supported backend range" | `rep_delay` outside the backend's range | Read `backend.rep_delay_range` before you set it | [Budgeting QPU time](../reference/ibm-quantum-compute-client.md#budgeting-qpu-time) |
| Error 8038: "A timing error occurred during execution of the input circuits" | Many mid-circuit measurements or resets for the repetition delay | Increase `options.execution.rep_delay` within `backend.rep_delay_range`, or reduce mid-circuit operations | [Budgeting QPU time](../reference/ibm-quantum-compute-client.md#budgeting-qpu-time), [Dynamic circuits](../reference/ibm-quantum-compute-client.md#dynamic-circuits-and-resets) |
| Errors 1218, 1250 or 1377: an instance time or usage limit was exceeded | Your instance's QPU allocation is used up | Stop submitting, read `service.usage()` for what the instance has used, and contact the event team | [Budgeting QPU time](../reference/ibm-quantum-compute-client.md#budgeting-qpu-time) |
| A twirled legacy `SamplerV2` job fails | `num_randomizations × shots_per_randomization` is smaller than the PUB's shots | Leave both at `"auto"`, or make their product at least the shot count | [Twirling options](../reference/ibm-quantum-compute-client.md#twirling-options-in-the-primitives) |
| A client-side Sampler or Estimator job returns more or fewer shots than you asked for | It runs exactly `num_randomizations × shots_per_randomization` shots | Set both explicitly, or accept the `"auto"` rounding | [Twirling options](../reference/ibm-quantum-compute-client.md#twirling-options-in-the-primitives) |
| Error 1555: "Post-selection filtering discarded all the shots" | Service-side post-selection, such as `NoiseLearnerV3Options.bit_flip_checks`, rejected every shot | Use the less strict `strategy="edge"`, or switch the checks off for that run | [Non-Markovian error checks](../reference/noise-management.md#post-selection-on-non-markovian-error-checks), [NoiseLearnerV3](../reference/ibm-quantum-compute-client.md#noiselearnerv3) |
| `NoiseLearnerV3` fails in local mode, or cannot learn a layer | It needs a real backend, and it learns only layers that can be Pauli-twirled; non-Clifford fractional `RZZ` layers cannot | Run it on hardware, on Clifford layers | [NoiseLearnerV3](../reference/ibm-quantum-compute-client.md#noiselearnerv3) |
| Local `Executor` fails with `AttributeError: '_semantic_role'` | The program is a plain Samplomatic `QuantumProgram` | Create programs with `qiskit_ibm_runtime.QuantumProgram`, and pass yours to mitigation tasks through `quantum_program=` | [Executor](../reference/ibm-quantum-compute-client.md#executor-and-quantumprogram), [qiskit-mitigation](../reference/noise-management.md#qiskit-mitigation-trex-zne-pea-and-pec) |
| A local client-side Estimator run fails with `ValueError: could not broadcast input array from shape (0, ...)` | The Estimator measures every qubit of the ISA circuit, and Aer cannot simulate a whole device such as the 156-qubit `FakeBoston` | Test the Estimator on a small backend, such as `GenericBackendV2(num_qubits=16)` | [Sampler and Estimator](../reference/ibm-quantum-compute-client.md#sampler-and-estimator-client-side-primitives), [Local test patterns](testing-and-tips.md#local-test-patterns) |
| `PEC.prepare` fails with one noise modifier per box when you apply shaded-light-cone scales | A limit of `qiskit-mitigation` 0.1.1 | Write your own PEC task that applies the scales | [Shaded light cones](../reference/qiskit-addons.md#shaded-light-cones-qiskit-addon-slc) |

## Reading results

| Symptom | Cause | Fix | See |
|---|---|---|---|
| `job.usage()` returns 0 or nothing right after a job finishes | Usage is recorded later | Read it again before you record it | [Practical tips](testing-and-tips.md#practical-tips), [Budgeting QPU time](../reference/ibm-quantum-compute-client.md#budgeting-qpu-time) |
| ZNE returns the unmitigated value, or the noise-factor circuits are identical | The two-qubit gates are fractional `rzz`, which the client-side Estimator's gate folding does not fold; no warning is raised | Fold the `rzz` gates yourself and extrapolate, or transpile without fractional gates | [Sampler and Estimator](../reference/ibm-quantum-compute-client.md#sampler-and-estimator-client-side-primitives), [qiskit-mitigation](../reference/noise-management.md#qiskit-mitigation-trex-zne-pea-and-pec) |
| Expectation values computed from `Executor` bits come out near zero | The measurement-twirl flips were not undone | Apply `measurement_flips.<register>`, or use the expectation-value helpers | [Executor](../reference/ibm-quantum-compute-client.md#executor-and-quantumprogram), [Expectation values](../reference/qiskit-addons.md#expectation-values-from-shot-data) |
| Bit order looks reversed | Qiskit bitstrings are little-endian: qubit 0 is the rightmost character | Index from the right, or use `BitArray` methods | [Expectation values](../reference/qiskit-addons.md#expectation-values-from-shot-data) |
| M3-corrected results are biased | The calibration ran without the measurement twirling your jobs used | Call `set_suppression_options(twirling={"enable_measure": True})` on the M3 object's `system` attribute (the runningman wrapper that mthree puts around an IBM backend) before `cals_from_system` | [M3](../reference/qiskit-addons.md#measurement-mitigation-with-m3-mthree) |
| Plausible results that disagree with an earlier run of the same code | A layout search after a recalibration chose different qubits | Record the layout with each job ID | [Practical tips](testing-and-tips.md#practical-tips) |

## Managed Workflows

| Symptom | Cause | Fix | See |
|---|---|---|---|
| A package your workflow imports is missing, or has the wrong version | The Fleets image ships a fixed set of packages, and `dependencies=` is deprecated and installs nothing | Check the image with `client.dependencies_versions()` or `client.dependency_report([...])`, then upload a wheel with `add_wheels()` and call `install_uploaded_wheels()` in the entrypoint | [Bring your own wheels](../reference/managed-workflows.md#bring-your-own-wheels) |
| `file_upload` rejects an `.h5` or `.pkl` file | The file store checks file types | Wrap the file in a `.tar.gz` archive | [Data and files](../reference/managed-workflows.md#data-and-files) |
| QPU calls from a long managed-workflow job start to fail | The runtime service's token expired | Call `get_runtime_service()` again before each submission | [Write, upload and run a workflow](../reference/managed-workflows.md#write-upload-and-run-a-workflow) |
| Inside a workflow, an `ImportError` for `generate_lucj_pass_manager` or for `qiskit_addon_sqd.trim` | The runtime image ships ffsim and `qiskit-addon-sqd` releases older than these APIs | Upload newer wheels with `add_wheels()`, or transpile the LUCJ circuit on your machine and upload it as QPY | [External dependencies](../reference/managed-workflows.md#external-dependencies) |
